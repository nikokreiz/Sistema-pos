# Sistema POS

Sistema de punto de venta e inventario para negocios y bazares en Chile.

## Objetivo
Permitir el control de inventario y la venta de artículos, cumpliendo la normativa chilena (SII, IVA, protección de datos y derechos del consumidor).

## Stack
- PHP (lógica del lado del servidor)
- MySQL / MariaDB
- HTML + CSS en archivos externos (`public/css`)

## Estructura
```
docs/        Requisitos, normativa y modelo de datos
database/    Esquema SQL y datos de ejemplo
src/         Código PHP (config, controllers, models, views)
public/      Punto de entrada web, CSS, JS e imágenes
```
